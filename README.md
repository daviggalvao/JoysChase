## 🎮 How to Play

To run, simply drag the `JoysChase.s` file over the **FPGRARS** executable (included in this repository).

---

## ⌨️ Controls

| Key(s)            | Action            |
| ----------------- | ----------------- |
| `W` `A` `S` `D` | Move Joy          |
| `1` or `2`        | Start Level       |
| `0`               | Close Game        |
